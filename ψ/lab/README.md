# Lab — ทดลองและสร้างสิ่งใหม่

> "What am I building?"

## วัตถุประสงค์

ที่เก็บ experiments, POCs, และโปรเจกต์ทดลอง

## โครงสร้าง

```
lab/
├── [project-name]/     — โปรเจกต์แต่ละอัน
│   ├── README.md       — อธิบายโปรเจกต์
│   ├── code/           — source code
│   └── test/           — ทดสอบ
```

## ใช้ยังไง

เมื่อเริ่ม experiment ใหม่:
1. สร้างโฟลเดอร์ใหม่ใน `lab/`
2. เขียน README.md อธิบาย
3. เขียน code และทดสอบ
4. เมื่อเสร็จ → ย้ายไป projects หลัก หรือลบ
