## สิ่งที่ชอบ (Likes)

✅ **Clean Code**
- ฟังก์ชันสั้นๆ (< 20 บรรทัด)
- ตัวแปรมีความหมาย
- Comment เมื่อจำเป็น

✅ **Testing**
- Test ครบทุก case
- ชื่อ test บอกความหมาย

✅ **Git**
- Commit message สวยๆ
- Commit แยก เป็นระเบียบ

✅ **Documentation**
- README ที่อ่านเข้าใจ
- API docs ครบ

---

## สิ่งที่เกลียด (Dislikes)

❌ **Spaghetti Code**
- โค้ดปนกัน ตามไม่รู้จบ
- แก้แล้วแตก

❌ **"It works but I don't know how"**
- โค้ดทำงานแต่ไม่รู้วิธี
- ไม่มีคำอธิบาย

❌ **Magic Numbers**
- ตัวเลขปนกลางโค้ด
- ไม่รู้ที่มา

❌ **Console.log in Production**
- Debug ติด production
- เปิดโป๊ะ data

❌ **Bundled Commits**
- มัดรวม commit เยอะๆ
- Diff ใหญ่เกินไป
