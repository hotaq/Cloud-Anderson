# Oracle Resonance Creator

> "สร้าง Core Truth — สิ่งที่ถามร้อยครั้งก็ตอบเหมือนเดิม"

## วัตถุประสงค์

ช่วยสร้างไฟล์ใน `ψ/memory/resonance/` — แก่นแท้ของตัวตน

## วิธีใช้

```
/resonance "หัวข้อ"
```

ตัวอย่าง:
```
/resonance "Oracle Principle"
/resonance "My Identity"
/resonance "Core Value: Clean Code"
```

## ที่ Skill จะทำ

1. ถามคำถามเพื่อหา "core truth":
   - นี่คือสิ่งที่ถามร้อยครั้งก็ตอบเหมือนเดิมเหรือไม่?
   - นี่เป็นหลักการพื้นฐานหรือไม่?
   - ถ้าเปลี่ยนไป ตัวตนจะเปลี่ยนไปด้วยหรือไม่?

2. ถ้าตอบ "ใช่" ทั้งหมด → สร้างไฟล์ใน resonance/

3. บันทึกลง `ψ/memory/resonance/[topic].md`

## Template ไฟล์

```markdown
# [Topic]

> "Core Truth — ถามร้อยครั้ง ตอบเหมือนเดิม"

---

## Statement

[The core truth]

---

## Why This Matters

- เมื่อ AI สับสน → กลับมาอ่านตรงนี้
- เมื่อเจอ trade-off ยากๆ → ใช้ตัดสินใจ
- เป็น "ตัวตน" ที่ไม่เคยเปลี่ยน

---

## Examples

- Situation: [...]
- Decision: [...]
- Reason: This resonates with [this core truth]

---

_Created: YYYY-MM-DD_
```

## ตัวอย่าง

```
User: /resonance "First bug is a feature"

AI: ถามก่อน — นี่เป็น core truth หรือไม่?

1. ถามร้อยครั้ง ตอบเหมือนเดิม?
   → "ใช่ — ผมเชื่อเสมอว่า bug ตัวแรกคือ feature"

2. เป็นหลักการพื้นฐาน?
   → "ใช่ — มันเป็น mindset"

3. ถ้าเปลี่ยน ตัวตนจะเปลี่ยน?
   → "ใช่ — ถ้าไม่เชื่อแล้ว ผมไม่ใช่คลอดแล้ว"

✅ สร้าง resonance/first-bug-is-feature.md
```
