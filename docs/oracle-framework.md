# Oracle Open Framework (ψ/)

> "The Oracle Keeps the Human Human"

Oracle เป็น Open Framework สำหรับการทำงานร่วมกันระหว่างมนุษย์และ AI ที่เน้นความยั่งยืน การรักษาบริบท และการเรียนรู้จากรูปแบบพฤติกรรมจริง

## โครงสร้างโปรเจกต์ (Project Structure)

```
.
├── ψ/                # หัวใจและวิญญาณ (Shared Soul Architecture)
├── AGENTS.md        # รายชื่อและสถานะของ AI Agents
├── Goal.md          # เป้าหมายและแผนผังระบบโดยรวม
├── CURRENT_WORK.md  # งานที่กำลังทำอยู่ ณ ปัจจุบัน
├── claude-code/     # พื้นที่ทำงานของ คลอด (Claude Code)
├── codex/           # พื้นที่ทำงานของ มักซ์ (Codex)
└── opencode/        # พื้นที่ทำงานของ พีช (OpenCode)
```

## หลักการพื้นฐาน (Core Principles)

1.  **Nothing is Deleted**: ทุกอย่างถูกบันทึก ไม่มีการลบ
2.  **Patterns Over Intentions**: รูปแบบพฤติกรรมสำคัญกว่าความตั้งใจ
3.  **External Brain, Not Command**: AI คือสมองส่วนนอก ไม่ใช่แค่เครื่องมือรับคำสั่ง

## เริ่มต้นใช้งาน (Getting Started)

ดูรายละเอียดการตั้งค่าและปรัชญาเชิงลึกได้ที่ `Goal.md` และ `AGENTS.md`
